TabBlackBox saves browser sessions on your device so you can find and restore your tabs. It does not send your saved sessions to the developer. There are no accounts, analytics, advertising or cloud sync.

What is saved

TabBlackBox saves tab URLs and titles, window and tab order, and pinned tabs. It also saves group names, colors and collapsed state, backup dates, session names and tags. Settings and interface preferences are also stored locally. Imported archives add the session information they contain.

TabBlackBox does not read page contents, form entries, cookies or passwords. Full URLs and titles can still contain sensitive information, including access tokens or local file paths. Incognito windows are excluded from capture.

When it is saved

New installations use manual backups. Automatic backups start when you enable them in Settings, with a 15-minute frequency by default. You can change the interval, pause or disable automatic backups, or use manual backups only.

The popup separately displays recently closed tabs from Chrome. That list is not saved as a TabBlackBox archive, and Chrome controls its retention.

Storage and deletion

Sessions are stored in this browser profile using IndexedDB. Older automatic backups are deleted according to your settings. The default limit is 100 MB, with no backup count limit. By default, automatic backups are not deleted based on how old they are. Saved sessions and the newest recovery backup are protected from automatic deletion.

You can delete saved sessions and older backups in the app. To remove all extension data, uninstall TabBlackBox. Exported files are separate copies and must be deleted separately.

Exports and security

Local records and exports are not encrypted by TabBlackBox. Anyone who can access an exported file can read it. Keep exports somewhere you trust. We cannot recover lost local data or deleted files.

Restoring or opening a saved link visits its destination normally. Website icons are requested through Chrome's favicon API. The browser and destination websites have their own privacy practices.

Permissions and use

Tab and group access lets you save and restore sessions. Alarms schedule backups. Unlimited storage supports large backup collections. Favicon access displays website icons. Session access shows recently closed tabs. File URL access lets you reopen local file links when you enable it in Chrome. The extension does not read file contents.

TabBlackBox uses information from Google APIs only for its session backup features. This use follows the Limited Use requirements of the Chrome Web Store User Data Policy.
