# TabBlackBox
Chromium extension for automatic backups, versioning, and restoration of browser tabs and sessions

Fresh installations open directly into the normal interface without an acceptance screen or an automatically opened tab. Use **Back up now** to save manually. To enable automatic backups, open **Settings** and turn on **Automatic backups**. The initial frequency is 15 minutes. Updates preserve existing backup settings and saved sessions.

## Privacy

Backups stay in the local browser profile. There are no accounts, analytics, or developer uploads. Saved URLs and titles may contain sensitive information, including access tokens and local file paths. Local records and exported files are not encrypted by TabBlackBox. Keep exports somewhere you trust. Privacy links in the popup and full-page header open the bundled policy offline.
